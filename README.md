# one-time-pad

Encode and decode messages according to the one time pad method.

## Usage

`usage: otp [-h] [--code-book] [--conversion] {encode,decode} ...`

`--code-book`and `--conversion` can be used to print the paths of the code book and conversion table.

### Encode

`usage: otp encode message`

### Decode

`usage: otp decode message`
